Manual de Usuario - Yogurt Batch (versión corta)

Hola, soy un estudiante y escribí esto rápido para que sepas usar la app.

Qué hace
Esta app es un backend que guarda recetas y controla lotes de yogur. Todo se hace por una API (no hay interfaz bonita).

Arrancar la app
1. Abre la terminal en la carpeta del proyecto.
2. Ejecuta:

   ./mvnw spring-boot:run

3. Entra a http://localhost:8080

Probar la API (fácil)
- Ver todas las recetas: GET /api/recipes
- Ver una receta: GET /api/recipes/{id}
- Crear receta: POST /api/recipes (envía JSON en el body)
- Actualizar: PUT /api/recipes/{id}
- Borrar: DELETE /api/recipes/{id}

Si quieres probar sin saber mucho, abre Swagger UI en http://localhost:8080/swagger-ui.html y haz click en los endpoints.

Ejemplo muy simple con curl (crear):

curl -X POST "http://localhost:8080/api/recipes" -H "Content-Type: application/json" -d '{"name":"Yogur","defaultMilkVolume":1000}'

Problemas comunes
- Si no arranca: asegúrate de tener Java y permisos.
- Si recibes error 400: revisa que el JSON tenga las claves correctas.
