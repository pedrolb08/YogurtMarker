Manual de Usuario - Yogurt Batch

Resumen
Este programa ayuda a gestionar recetas y lotes de yogur artesanal. La interfaz principal es una API REST que permite crear, consultar, actualizar y eliminar recetas, además de gestionar lotes y monitorización de temperatura.

Requisitos previos
- Tener Java 11+ instalado
- Tener Maven instalado (o usar los scripts `mvnw` incluidos)
- Un cliente HTTP (curl, Postman o similar)

Cómo usar (para una persona no técnica)
1. Iniciar la aplicación
   - Ejecuta el archivo `mvnw spring-boot:run` en la carpeta del proyecto o usa tu IDE para ejecutar `DemoApplication`.
   - La aplicación por defecto arranca en `http://localhost:8080`.

2. Usar la documentación Swagger
   - Abre `http://localhost:8080/swagger-ui.html` o la ruta provista por la configuración OpenAPI.
   - Desde ahí puedes ver todos los endpoints, probar requests y ver ejemplos de respuesta.

3. Operaciones comunes
   - Ver todas las recetas: GET `http://localhost:8080/api/recipes`
   - Ver receta por id: GET `http://localhost:8080/api/recipes/{id}`
   - Crear receta: POST `http://localhost:8080/api/recipes` con body JSON que contenga los campos de la receta.
   - Actualizar receta: PUT `http://localhost:8080/api/recipes/{id}` con body JSON nuevo.
   - Eliminar receta: DELETE `http://localhost:8080/api/recipes/{id}`
   - Ver recetas activas: GET `http://localhost:8080/api/recipes/active`
   - Filtrar por dificultad: GET `http://localhost:8080/api/recipes/difficulty/{EASY|MEDIUM|DIFFICULT|EXPERT}`

4. Ejemplo rápido usando curl (crear receta)

curl -X POST "http://localhost:8080/api/recipes" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Yogur natural",
    "description": "Yogur casero simple",
    "defaultMilkVolume": 1000,
    "defaultStarterAmount": 10,
    "heatingTemperature": 85,
    "heatingDuration": 10,
    "innoculationTemperature": 42,
    "incubationTemperature": 42,
    "minIncubationTime": 6,
    "maxIncubationTime": 12,
    "refrigerationTime": 4,
    "difficulty": "EASY",
    "tips": "Usa leche entera para mejor textura"
  }'

5. Soporte y errores comunes
   - Si no se inicia la app: revisa que Java y Maven estén instalados. Ejecuta `./mvnw spring-boot:run` para ver logs.
   - Si la API devuelve 400 al enviar JSON: verifica la estructura del body y tipos de datos.

Notas finales
- Este manual cubre el uso básico vía API. Para uso más avanzado (ej. integración con dispositivos de medición de temperatura), revisa el manual técnico.

Fin del manual de usuario.
