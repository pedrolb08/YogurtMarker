Manual Técnico - Yogurt Batch 

Qué es
Es un backend en Java con Spring Boot que ofrece una API REST para recetas y lotes de yogur. No tiene UI aparte de Swagger.

Tech stack
- Java
- Spring Boot (Web, Data JPA)
- Maven (con mvnw)
- Lombok
- OpenAPI/Swagger (anotaciones io.swagger.v3)

Estructura importante
- `src/main/java/com/pedro/demo/controller` - controladores REST (p. ej. `RecipeController`).
- `.../demain/repository` - repositorios JPA.
- `.../domain/model` - entidades (Recipe, YogurtBatch, etc.).
- `.../dto` - objetos para enviar/recibir datos.

Cómo ejecutar rápido
1. `./mvnw spring-boot:run`
2. Ir a `http://localhost:8080` y abrir Swagger UI para probar.

Notas para desarrollar
- Usa Lombok (asegúrate plugin en IDE). 
- Los controladores usan anotaciones de OpenAPI para documentar.
- Añade `@Valid` y DTOs si quieres validar entradas.

Comandos útiles
- Compilar: `./mvnw clean package`
- Tests: `./mvnw test`

Fin del manual técnico.
